# First CI Pipeline Project

## Project Description
This project demonstrates Continuous Integration (CI) using Python, Pytest, and GitHub Actions.

## Project Structure
- codes: Contains Python programs.
- test_cases: Contains Python test cases.
- .github/workflows: Contains GitHub Actions workflow files.

## Technologies Used
- Python
- Pytest
- GitHub Actions

## How to Run Tests
Install dependencies:

pip install -r requirements.txt

Run tests:

pytest
